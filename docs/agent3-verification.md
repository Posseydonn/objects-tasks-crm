# Проверка экранов агента 3

**Актуализация 5 ноября:** оставшиеся интеграционные сценарии и публикация затем выполнены по отдельному поручению пользователя; см. `frontend-release.md`. Ниже — результат первоначальной проверки отдельных экранов.

Дата: 4–5 ноября 2026 года, МСК. Локальные экраны React/Ant Design, Chromium через Playwright CLI, настоящие тестовые Supabase Auth-сессии. Маршруты подключались во временном HashRouter-стенде без изменения `src/App.tsx`. Это не проверка опубликованного приложения.

## Фактически выполнено

- Постановщик видит три исходных объекта и все пять статусов задач общего объекта.
- Создание отдельного объекта через форму; пустая отправка запрещена; объект появился после реального RPC и повторного чтения.
- Редактирование адреса объекта, сохранённый адрес виден в карточках объекта и задачи.
- Пустое состояние задач объекта, создание задачи с выбором исполнителя; заполнены название, описание, объект и исполнитель.
- В карточке показаны поля, имя автора, дата и начальная история создания.
- У исполнителя нет редактирования/удаления; из новой задачи доступно взятие в работу, затем отправка на проверку.
- Постановщик возвращает на доработку: комментарий из пробелов отклонён; содержательный комментарий сохранён и виден исполнителю в истории.
- Исполнитель продолжает работу, повторно отправляет на проверку; постановщик принимает. Итог: 7 событий истории, включая создание. Принятая задача не предлагает переходов статуса.
- Изменено описание уже принятой задачи; дождались закрытия формы и перечитанных данных. Статус сохранился.
- Другой исполнитель открывает прямую ссылку на тестовую задачу: «Недоступна или не найдена», данные карточки не показаны.
- «Мои задачи» другого исполнителя содержит его задачи с названиями объектов и статусами. Поиск без совпадений показывает пустое состояние, очистка восстанавливает список.
- Отключение сети и обновление: данные заменяются загрузкой, затем русской ошибкой с кнопкой «Повторить». После включения сети и повторения список восстановлен. Supabase возвращает сетевую ошибку как обычный объект, поэтому общий обработчик показывает нейтральный русский текст.
- Ширина 390 px: карточка и «Мои задачи» не расширяют `main`; таблица прокручивается внутри контейнера. Снимки визуально просмотрены. Шапка временного стенда не адаптирована и не оценивает шапку штатного приложения.
- После добавления AbortSignal: специально задержан запрос объектов; переход на другой экран вызвал `requestfailed` отменённого запроса, новый экран загрузился без устаревших данных.
- Удаление тестовой задачи через подтверждение вернуло на пустой объект; удаление тестового объекта через подтверждение убрало его из списка. Исходные демоданные не редактировались. История тестовой задачи сохранена штатным мягким удалением.

## Граница результата

Не выполнены агентом 3: изменение общего роутера, commit/push/deploy и финальная приёмка публичной версии. Не повторялись проверки безопасности/конкуренции агента 2. Перенос и переназначение реализованы через штатный update_task, но отдельный браузерный сценарий этих двух действий остаётся агенту 4. Одновременная смена аккаунта без reload в штатном каркасе также остаётся общей приёмке; при проверке использовались настоящие сессии трёх ролей/аккаунтов с перезагрузкой.
